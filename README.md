## Stuart Guppy, PhD, CSCS, AES
Exercise and sport science academic with interests in performance testing, measurement validity, and research methods.

My GitHub profile is a collection of tools developed through my academic work. These tools are primarily built to solve problems I encounter in my own research and are made publicly available to support transparency and reproducibility.
## Research Tools
**cmj-processor:**
Custom Python workflow for processing and analysing countermovement jump force-time curve data

**imtp-processor:**
Custom Python workflow for processing and analysing isometric mid-thigh pull force-time curve data

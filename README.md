## Stuart Guppy, PhD, CSCS, AES
Exercise and sport science academic with interests in strength and conditioning, performance testing, measurement validity, and research methods.

My GitHub profile is a collection of tools developed through my teaching and research. Most of these projects originate from practical problems I've encountered when conducting research, and are made publicly available to support transparency and reproducibility.
## Research Tools
**cmj-processor**
Custom Python workflow for processing and analysing countermovement jump force-time curve data

**imtp-processor**
Custom Python workflow for processing and analysing isometric mid-thigh pull force-time curve data

## Current Development
My research software is developed primarily for my own academic workflows. Projects are released publicly where they may be useful to others or are included in one of my publications.
